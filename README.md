# Omar Abdulghani - Personal Portfolio

Welcome to the source code of my personal portfolio platform! 

This repository contains the full-stack code for my responsive, animated portfolio, designed to showcase my journey as a Tech-Driven Creative Specialist, my UX/UI design work, and my self-initiated web development projects.

[www.omarabdulghani.com](https://www.omarabdulghani.com)

## 💡 About the Project
I built this portfolio to serve as a central hub for my professional identity. It bridges the gap between creative business strategy and technical execution. The platform is designed with a focus on:
- **Clean UX/UI**: A sleek aesthetic with smooth micro-interactions that feels premium and engaging.
- **Performance**: Fast loading times and completely responsive, fluid layouts across all devices.
- **Modular Architecture**: A scalable component system that makes it incredibly easy to add new case studies, technical builds, and blog posts over time.

## 🛠️ Tech Stack
This project leverages a modern, highly optimized web architecture:

**Frontend Core:**
- **React (v19)**: Component-based UI architecture.
- **TypeScript**: For robust, type-safe development and self-documenting code.
- **Vite**: Next-generation, blazing-fast frontend build tooling.

**Styling & UI:**
- **Tailwind CSS (v4)**: Utility-first styling for rapid UI development and responsive design.
- **Framer Motion**: For buttery-smooth page transitions, spring physics, and scroll animations.
- **Radix UI**: Unstyled, accessible UI primitives for complex accessible components (dialogs, accordions, popovers).
- **Lucide React**: Clean, consistent SVG iconography.

**Routing & State:**
- **Wouter**: A minimalist, lightweight routing solution for seamless single-page application navigation.
- **React Hook Form & Zod**: For complex form state management and strict schema validation.

**Backend & Deployment:**
- **Express.js**: Lightweight Node.js server for API routes and static asset serving in production environments.
- **Esbuild**: For lightning-fast server bundling.

## ⚙️ How to Run Locally

If you'd like to explore the codebase locally, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/omar-abdelgani/omar-portfolio.git
   cd omar-portfolio
   ```

2. **Install dependencies:**
   This project uses `pnpm` as the package manager.
   ```bash
   pnpm install
   ```

3. **Start the development server:**
   ```bash
   pnpm run dev
   ```
   The application will instantly hot-reload at `http://localhost:5173` (or the port Vite assigns).

4. **Build for production:**
   ```bash
   pnpm run build
   pnpm run start
   ```
